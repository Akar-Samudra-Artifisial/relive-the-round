# Calibration anchors: lotus -> Cistern

Generated by `uv run relive-calib-anchors --map lotus`. The anchor files live in the git-ignored `data/calib/` (derived from GRID data); this page holds counts and method only.

## Method

- uv = `geometry.to_uv` (valorant-api minimap calibration, origin top-left), the same space the level files use; the web warp maps it to Cistern (`web/src/maps/cistern.ts`).
- Callout anchors: valorant-api callout label positions converted to uv.
- Plant anchors: every first spike plant per round, site = nearest site callout; component-median uv + p50 radius.
- Spawn anchors: player positions at the end of the buy phase, per side; component-median uv.
- Hotspots: busiest cells of a 20x20 grid over all in-round position samples (cells >= 2 apart), mean uv per cell.
- Density raster: 100x100 counts of the same samples (`<map>-density.json`) for the debug overlay; extent = p1/p99 per axis.

## Result

- Sample: 338 series, 338 games, 6999 rounds, 1527119 position samples.
- Callout anchors: 28 (A 12, Attacker Side 1, B 4, C 10, Defender Side 1).
- Plant anchors: 3 sites (A n=1890, B n=942, C n=1862); p50 radius uv: A 0.038, B 0.053, C 0.046.
- Spawn anchors: 2 (attacker n=35040, defender n=35040).
- Hotspots: 8; extent u [0.07, 0.92], v [0.21, 0.83].
- Ready-made landmarks for the Cistern warp (p50 radius <= 0.1 uv): a-site, b-site, c-site.
- Diffuse anchors left out of the landmarks: atk-spawn (p50 radius 0.128), def-spawn (p50 radius 0.268).

## Caveats

- The buy-phase-end snapshot does not pin spawns tightly: position samples only refresh on events, so some players still show where they stood earlier. Treat spawn anchors with a large p50 radius as hints only; place those Cistern landmarks from callouts.
- Callouts are label anchors, not area centres; plant medians are the most precise site anchors.
