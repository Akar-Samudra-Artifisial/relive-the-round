# Calibration anchors: haven -> Kiln

Generated by `uv run relive-calib-anchors --map haven`. The anchor files live in the git-ignored `data/calib/` (derived from GRID data); this page holds counts and method only.

## Method

- uv = `geometry.to_uv` (valorant-api minimap calibration, origin top-left), the same space the level files use; the web warp maps it to Kiln (`web/src/maps/kiln.ts`).
- Callout anchors: valorant-api callout label positions converted to uv.
- Plant anchors: every first spike plant per round, site = nearest site callout; component-median uv + p50 radius.
- Spawn anchors: player positions at the end of the buy phase, per side; component-median uv.
- Hotspots: busiest cells of a 20x20 grid over all in-round position samples (cells >= 2 apart), mean uv per cell.
- Density raster: 100x100 counts of the same samples (`<map>-density.json`) for the debug overlay; extent = p1/p99 per axis.

## Result

- Sample: 419 series, 419 games, 8610 rounds, 1736208 position samples.
- Callout anchors: 21 (A 7, Attacker Side 1, B 2, C 7, Defender Side 1, Mid 3).
- Plant anchors: 3 sites (A n=2361, B n=917, C n=2467); p50 radius uv: A 0.017, B 0.001, C 0.011.
- Spawn anchors: 2 (attacker n=43085, defender n=43085).
- Hotspots: 8; extent u [0.2, 0.79], v [0.1, 0.9].
- Ready-made landmarks for the Kiln warp (p50 radius <= 0.1 uv): a-site, atk-spawn, b-site, c-site.
- Diffuse anchors left out of the landmarks: def-spawn (p50 radius 0.274).

## Caveats

- The buy-phase-end snapshot does not pin spawns tightly: position samples only refresh on events, so some players still show where they stood earlier. Treat spawn anchors with a large p50 radius as hints only; place those Kiln landmarks from callouts.
- Callouts are label anchors, not area centres; plant medians are the most precise site anchors.
